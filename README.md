# 바라시 (ㅂㄹㅅ)

촬영 현장 콜시트 웹앱. 홈 화면에 설치해서 앱처럼 쓰는 설치형 웹앱(PWA)이다.

## 파일 구성

- `index.html` : 앱 전체 (화면, 기능, 시연용 데이터)
- `manifest.webmanifest` : 앱 이름, 아이콘, 설치 설정
- `sw.js` : 오프라인 캐시 (신호 없는 로케에서도 마지막 콜시트가 열림)
- `*.png` : 앱 아이콘 (ㅂㄹㅅ 로고)

## GitHub Pages로 배포하기

1. GitHub에서 새 저장소 만들기 (예: `barasi`, Public)
2. 이 폴더 안의 파일 9개를 전부 업로드 (Add file > Upload files)
3. Settings > Pages > Branch를 `main`, 폴더를 `/ (root)`로 두고 Save
4. 1~2분 뒤 `https://아이디.github.io/barasi/` 주소로 열림

## 폰에 설치하기

- 아이폰: 사파리로 주소 열기 > 공유 버튼 > 홈 화면에 추가
- 안드로이드: 크롬으로 주소 열기 > 메뉴 > 앱 설치
- 앱 안에서도 오른쪽 위 "○○ 기준" 버튼 > "홈 화면에 앱으로 설치하기"로 안내가 나온다.

## 업데이트할 때

`index.html`을 고친 뒤 `sw.js` 맨 위 `VERSION` 숫자를 올려서(`barasi-v1` → `barasi-v2`) 같이 올리면, 설치된 폰에도 새 버전이 반영된다.

## 서버 (Supabase 프로젝트 `barasi`, 서울 리전)

- 로그인, 회차 데이터, 촬영 완료 체크와 지연, 대본, 자료 파일이 모두 서버에 저장되고 팀 전원에게 공유된다.
- 비밀번호는 암호화되어 저장되고, 테이블은 외부에서 직접 읽을 수 없다. 10분에 10번 틀리면 잠긴다.
- 자료 파일은 비공개 저장소(`barasi-files`)에 올라가고, 1시간짜리 임시 링크로만 열린다. 파일당 50MB까지.
- 열려 있는 동안 30초마다, 그리고 앱으로 돌아올 때마다 최신 상태를 다시 불러온다.
- 신호가 없을 때는 마지막으로 받은 콜시트를 보여준다.
